# Runtime and history evidence contract

Build one time-aligned process/resource timeline around the symptom window.

Observe process identity and lifetime, exit status, journal evidence, cgroup/container state, CPU, memory, swap, file descriptors, disk pressure, temperature, and throttling. Compare the affected process with competitors on the same board. Prefer bounded samples and existing historical logs.

Distinguish crash, OOM kill, operator/service stop, watchdog restart, resource starvation, and downstream silence. A process being present does not prove that its ROS callbacks are making progress.
